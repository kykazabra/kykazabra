**What I work on**

- **LLM systems that run in production** — agents and multi-step pipelines,
  RAG and hybrid search, text2sql, multimodal retrieval, speech-to-text at scale
- **Making model quality measurable** — evaluation harnesses, LLM-as-a-judge,
  benchmarks against human ground truth, prompt regression tests
- **Keeping them affordable** — multi-vendor gateways with fallbacks, batching,
  caching, per-request cost attribution
- **Backend engineering** — Python services and APIs, async workers,
  multi-tenant data isolation, integrations with external systems
- **Data platforms** — ETL, warehouse marts, analytics and dashboards
- **Shipping and operating** — IaC, CI/CD, observability, on-prem delivery

Before that: AI/RnD in a large bank — text2sql agents, multimodal search,
NLP products on domestic LLMs.
